# 🚀 Learn JS DOM With Fun

Welcome to my journey of mastering the **JavaScript Document Object Model (DOM)**! This repository is dedicated to learning JS DOM from the absolute basics through fun, interactive, and mini-projects.

## 🌟 Overview
The goal of this repo is to transform a static web page into a dynamic experience using JavaScript. Instead of boring lectures, I am learning by doing—building small, "fun" features that react to user input.

## 🛠️ Tech Stack
- **HTML5**: For the structure.
- **CSS3**: For the styling and animations.
- **JavaScript (ES6+)**: To bring everything to life!

## 📂 Project Structure
Each task is built using a clean separation of concerns:
- `index.html` - The skeleton.
- `style.css` - The skin/design.
- `script.js` - The brain/logic.

## 📝 Roadmap & Milestones
- [x] **Project 01: Magic Color Changer** - Learning `getElementById` and `style` manipulation.
- [ ] **Project 02: Mood Switcher** - Mastering text and emoji updates via events.
- [ ] **Project 03: The Counter Pro** - Working with numerical data and logic.
- [ ] **Project 04: Dark Mode Toggle** - Practicing class toggling.
- [ ] **Project 05: Secret Message Revealer** - Understanding visibility and display.

## 🚀 How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Open the folder in **VS Code**.
3. Launch `index.html` using **Live Server** or simply open it in any browser.
